Cloud Concepts Question
What is the difference between Vertical and Horizontal Scaling?
🔄 Tap anywhere to reveal African explanation
Mama Cloud Answer Concept Solved
Vertical (Scale UP) = Bigger single machine.
Horizontal (Scale OUT) = More machine instances.
💡 Mnemonic: UP = Upgraded engine | OUT = Outnumbering with more engines.
